## Промпт 1

**Цель:** Согласовать архитектуру проекта перед началом реализации кода.

**Промпт:**

```
Я хочу создать учебное full-stack приложение "Мини-анкета".

Используемый стек:
- Backend: Node.js + TypeScript + Express
- Frontend: React + Vite + TypeScript

Требования к приложению:

Backend:
- GET /questions — возвращает список из 3–5 заранее определенных вопросов анкеты.
- POST /answers — принимает ответы пользователя и хранит их в памяти приложения (без базы данных).

Frontend:
- Загружает вопросы через GET /questions.
- Отображает форму анкеты.
- Отправляет ответы через POST /answers.
- После успешной отправки показывает сообщение "Спасибо!".

Это учебный проект, поэтому архитектура должна быть максимально простой, понятной и соответствовать лучшим практикам.

Пока не создавай код и не изменяй файлы.

Сначала:
1. Предложи структуру проекта.
2. Объясни назначение каждой папки.
3. Опиши, какие файлы будут ключевыми.
4. Кратко опиши последовательность реализации проекта.

После этого дождись моего подтверждения.
```

## Промпт 2

**Цель:** Реализовать backend приложения по согласованной архитектуре.

**Промпт:**

```
Используя ранее согласованную архитектуру проекта, реализуй backend приложения "Мини-анкета".

Технологический стек:
- Node.js
- TypeScript
- Express

Требования:
1. Создай структуру проекта внутри каталога backend.
2. Настрой TypeScript и необходимые npm-скрипты для разработки и запуска приложения.
3. Реализуй два REST API:

GET /questions
- возвращает массив из 3–5 заранее определенных вопросов анкеты в формате JSON.
POST /answers
- принимает ответы пользователя в формате JSON;
- сохраняет ответы в памяти приложения (без использования базы данных);
- возвращает успешный HTTP-ответ после сохранения.

4. Раздели код по ответственности в соответствии с предложенной архитектурой:
- data — хранение вопросов;
- routes — обработчики API;
- store — in-memory хранилище ответов;
- types — общие интерфейсы;
- app.ts — настройка Express-приложения.

5. Используй строгую типизацию TypeScript.

6. Добавь базовую обработку ошибок там, где это необходимо.

7. После генерации:
- установи необходимые зависимости;
- убедись, что проект успешно компилируется;
- исправь обнаруженные ошибки, если они возникнут;
- запусти backend локально.

8. После успешного запуска покажи:
- итоговую структуру backend;
- список созданных файлов;
- команды для запуска проекта;
- пример запросов для проверки API через curl.
```

## Промпт 3

**Цель:** Реализовать frontend приложения, интегрированный с уже готовым backend.

**Промпт:**

```
Backend приложения уже реализован и протестирован.
Используя ранее согласованную архитектуру проекта, реализуй frontend приложения "Мини-анкета".
Технологический стек:
- React
- TypeScript
- Vite
Frontend должен работать с уже существующим backend через REST API.
Требования:
1. Создай структуру проекта внутри каталога frontend.
2. Настрой Vite, TypeScript и необходимые npm-скрипты.
3. Реализуй слой работы с API в каталоге src/api.
Создай функции:
- getQuestions() — выполняет GET /questions
- submitAnswers() — выполняет POST /answers
Используй реальные HTTP-запросы к backend.
4. Реализуй компоненты:
SurveyForm
- получает список вопросов через API;
- отображает форму анкеты;
- позволяет пользователю заполнить ответы;
- при отправке вызывает submitAnswers().
ThankYou
- отображает сообщение "Спасибо!" после успешной отправки анкеты.
5. Реализуй App.tsx.
Он должен:
- загружать вопросы при открытии приложения;
- отображать индикатор загрузки;
- отображать сообщение об ошибке, если API недоступно;
- отображать форму анкеты;
- после успешной отправки переключаться на экран "Спасибо!".
6. Используй:
- функциональные компоненты React;
- React Hooks;
- строгую типизацию TypeScript;
- понятную структуру компонентов.
7. Если для работы frontend потребуется настройка CORS на backend, внеси необходимые изменения в backend.
8. После генерации:
- установи необходимые зависимости;
- убедись, что frontend успешно собирается;
- исправь найденные ошибки;
- запусти frontend;
- убедись, что frontend успешно взаимодействует с backend.
9. После завершения покажи:
- структуру frontend;
- список созданных файлов;
- команды для запуска frontend;
- краткое описание того, как frontend взаимодействует с backend.
```
