# Проверки качества

Перед сдачей изменений в демо-проекте должны проходить две проверки.

## Тесты

Команда: `node --test 'tests/**/*.test.ts'` (в `package.json` — `npm test`).
Используется встроенный раннер `node:test`, TypeScript запускается напрямую (Node.js ≥ 22.18).
Тесты лежат в `tests/` и называются `*.test.ts`.

## Проверка типов

Команда: `tsc --noEmit -p tsconfig.json` (`npm run typecheck`).
Проверяется только `src/`, режим `strict`.

## Запуск через MCP

Обе проверки доступны агенту через инструмент `run_check` с параметром `check: "test"` или `check: "typecheck"`.
Другие команды запускать нельзя.
