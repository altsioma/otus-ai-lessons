# Обработка ошибок

Модуль корзины бросает только `CartError` (`src/errors.ts`). У ошибки есть поле `code`.

## Коды ошибок

| Код | Когда |
|---|---|
| `INVALID_PRICE` | цена отрицательная или не число |
| `INVALID_QUANTITY` | количество не целое, не положительное или больше `MAX_QUANTITY_PER_ITEM` (99) |
| `ITEM_NOT_FOUND` | удаление позиции, которой нет в корзине |
| `INVALID_DISCOUNT` | скидка нарушает правила из «Скидки» |

## Правила

- Проверяйте входные данные на границе модуля и бросайте `CartError` с понятным сообщением.
- Не глотайте ошибки: перехватывайте только там, где можете обработать.
- Для проверки типа используйте `isCartError(error)`, а не сравнение строк сообщения.
- В тестах проверяйте `code`, а не текст сообщения.
